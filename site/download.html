Get DeskDot

Install DeskDot like any other app

One file for Windows, Mac or Android. Free, no account. Close the iDotMatrix phone app first: the panel takes one Bluetooth connection at a time.

Tick the box to turn on the download buttons.

For this device

Windows

Windows 10/11 (64-bit), 80 MB

First install, step by step
  1. Open the file you downloaded. It's a normal setup program.
  2. If Windows SmartScreen says it protected your PC, click More info, then Run anyway. It says this because DeskDot is new and not yet widely downloaded.
  3. Follow the steps. You can tick Start DeskDot when I sign in.
  4. DeskDot opens the studio in your browser and sits in the tray, next to the clock.

Mac

Apple silicon (M1 and newer), 84 MB · Intel Mac, 76 MB

First install, step by step
  1. Not sure which Mac you have? Apple menu → About This Mac: “Apple M1” (or M2, M3…) means Apple silicon, “Intel” means Intel.
  2. Open the disk image and drag DeskDot into Applications.
  3. The first time, right-click (or Control-click) DeskDot and choose Open, then Open again. If macOS still blocks it, go to System Settings → Privacy & Security and click Open Anyway.
  4. Allow Bluetooth when macOS asks, so DeskDot can reach the panel.

Android

First install, step by step

  3. Open DeskDot and allow Nearby devices so it can find the panel over Bluetooth.

System requirements

  • Windows 10/11 (64-bit) with Bluetooth LE: verified on real panels.
  • macOS 11 or newer, Apple silicon or Intel: installers are new in 3.8.0 and less tested than Windows.
  • Android 8 or newer: the phone itself runs DeskDot and drives the panel (beta).
  • Raspberry Pi OS / Debian / Ubuntu (BlueZ): from the source. See Compatibility.
  • Bluetooth Low Energy (4.2 or newer recommended) and the panel within about 5 m.

Hardware notes

  • DeskDot is unofficial software. It talks to your panel over Bluetooth using its publicly observable protocol. It does not change the panel's firmware.
  • Using third-party software may affect the manufacturer's support or warranty. Check their terms.
  • Follow the manufacturer's safety instructions (power supply, heat, brightness, continuous use).

System requirements

  • Windows 10/11 (64-bit) with Bluetooth LE: verified. Raspberry Pi OS / Debian / Ubuntu (BlueZ): supported. macOS: untested. Android 8+ (64-bit): beta. See Compatibility.
  • Bluetooth Low Energy (4.2 or newer recommended) and the panel within about 5 m.
  • For the source route: git, uv (brings Python 3.13) and Node.js 20+ to build the studio once.

Hardware notes

  • DeskDot is unofficial software. It talks to your panel over Bluetooth using its publicly observable protocol. It does not change the panel's firmware.
  • Using third-party software may affect the manufacturer's support or warranty. Check their terms.
  • Follow the manufacturer's safety instructions (power supply, heat, brightness, continuous use).

Get started in a minute

You need an iDotMatrix 32×32 panel, a computer with Bluetooth, uv and Node.js. Close the iDotMatrix phone app first: the panel accepts one connection at a time.

$ git clone https://github.com/shivpatel2468/idotmatrix.git dotdeck && cd dotdeck
$ uv sync --extra mcp
$ (cd web && npm ci && npm run build)
$ uv run dotdeck serve          # → open http://127.0.0.1:8765
$ uv run dotdeck serve --sim    # no panel yet? use the simulator

Always on: Raspberry Pi · Android phone (beta)

About the panel

Measured on a real unit. These are the numbers DotDeck is built around.

Display32 × 32 RGB LEDs, 1,024 pixels
ConnectionBluetooth LE, advertises as IDM-xxxxxx, one connection at a time
Live frames~9 fps for simple frames, ~5–6 fps for full scenes
Native animationGIFs stored and looped by the panel: smooth at ≤ 10 fps, up to 40 KB
Brightness5–100 %, screen on/off, flip 180°, night mode
HostsWindows ✅ · Raspberry Pi / Linux 🟡 · macOS 🟡 · Android 🧪 beta

New: a fruit-fly brain that plays the apps

In 2024 the FlyWire consortium, with AI reconstruction built with Google Research, mapped every connection in an adult fruit-fly brain: 139,255 neurons and about 54.5 million synapses. The goal is to simulate its visual-to-motor wiring, feed it the panel's 32×32 frame like a compound eye, and let it play. The first version is in: a model of that circuit plays any game from pixels alone, and lives in its own Fly Brain app.

FlyWire · Nature, Oct 2024

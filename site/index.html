What it is

One engine owns the panel. Everything else talks to it.

DeskDot runs on your computer or a Raspberry Pi and keeps the Bluetooth link smooth. Drive it from the studio, your phone, scripts or an AI agent.

The engine

Bakes loops into GIFs the panel plays on its own, streams only what changes, and reconnects by itself.

The studio

Playlists, presets and live settings with an LED-accurate preview. See the studio.

The MCP server

21 tools let Claude and other agents see the panel, run apps, draw pixel art and notify you. Set it up.

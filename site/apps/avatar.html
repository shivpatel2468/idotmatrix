Pixel Avatar

Minecraft faces, GitHub identicons and DiceBear pixel characters — pixel-exact, with a name tag.

Try it

render a frame to PNG (no panel needed)
$ uv run deskdot preview avatar --settings '{"source":"github"}' --out avatar.png
show it on your panel (engine running)
$ curl -X POST http://127.0.0.1:8765/api/apps/avatar/activate

Or ask your agent: “Show Pixel Avatar on my panel”. It calls show_app with "avatar". New here? Set up DeskDot first.

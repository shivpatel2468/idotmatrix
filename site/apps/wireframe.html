3D Wireframe Vector

Retro 80s 3D vector graphics and 4D tesseract holo-display with depth cueing.

Try it

render a frame to PNG (no panel needed)
$ uv run deskdot preview wireframe --settings '{"shape":"icosahedron"}' --out wireframe.png
show it on your panel (engine running)
$ curl -X POST http://127.0.0.1:8765/api/apps/wireframe/activate

Or ask your agent: “Show 3D Wireframe Vector on my panel”. It calls show_app with "wireframe". New here? Set up DeskDot first.

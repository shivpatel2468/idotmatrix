Latest Plex or Jellyfin additions as posters, plus who's streaming now.

Try it

render a frame to PNG (no panel needed)
$ uv run deskdot preview mediaserver --settings '{"server":"jellyfin"}' --out mediaserver.png
show it on your panel (engine running)
$ curl -X POST http://127.0.0.1:8765/api/apps/mediaserver/activate

Or ask your agent: “Show Media Server on my panel”. It calls show_app with "mediaserver". New here? Set up DeskDot first.

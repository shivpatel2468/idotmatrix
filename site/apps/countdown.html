Countdown

Counts down to any moment — days, then hours, then a live seconds clock.

Put it on your panel Source code (MIT)

At a glance

OutputLiveRendered by the engine and streamed over Bluetooth as its data changes (about 5–9 frames a second).
Settings4every one editable live in the studio, or by an agent with update_app_settings
Source code (MIT)extras.pysrc/deskdot/apps/extras.py

Try it

render a frame to PNG (no panel needed)
$ uv run deskdot preview countdown --settings '{"style":"days"}' --out countdown.png
show it on your panel (engine running)
$ curl -X POST http://127.0.0.1:8765/api/apps/countdown/activate

Or ask your agent: “Show Countdown on my panel”. It calls show_app with "countdown". New here? Set up DeskDot first.

Try it

render a frame to PNG (no panel needed)
$ uv run deskdot preview composer --settings '{"background":"solid"}' --out composer.png
show it on your panel (engine running)
$ curl -X POST http://127.0.0.1:8765/api/apps/composer/activate

Or ask your agent: “Show Text Studio on my panel”. It calls show_app with "composer". New here? Set up DeskDot first.

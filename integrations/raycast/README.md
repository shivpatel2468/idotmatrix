# DeskDot for Raycast

Search and drive your iDotMatrix panel from Raycast (macOS and Windows) through the DeskDot engine's HTTP API.
See [docs/LAUNCHERS.md](../../docs/LAUNCHERS.md#raycast) for install steps.

Commands: **Search DeskDot Apps** (live previews; ↵ show on panel, ⌘↵ open its settings in the studio, play games
with the fruit fly) · **DeskDot Controls** · **DeskDot Presets** · **Send to Panel**.

Preference: *Engine URL* (default `http://127.0.0.1:8765`). The engine must be running (`uv run deskdot serve`).
